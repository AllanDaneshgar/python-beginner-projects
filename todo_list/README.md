# 📝 Todo List Manager

A simple yet powerful command-line todo list application built with Python. Automatically saves your tasks in a JSON file.

## ✨ Features

### Core Features
- ✅ **Add new tasks** with title, category, and priority
- ✅ **View all tasks** or only pending ones
- ✅ **Mark tasks as done** with completion timestamp
- ✅ **Delete tasks** with confirmation
- ✅ **Search tasks** by keyword
- ✅ **Task statistics** with completion rates

### File Management
- 💾 **Automatic save** to `tasks.json`
- 📂 **JSON storage** for easy data portability
- 🔄 **Persistent data** across sessions

### User Experience
- 🎨 **Colorful emoji** interface
- 📊 **Visual statistics**
- ⚠️ **Error handling** for invalid inputs
- 🔍 **Search functionality**

## 🚀 Quick Start

### Prerequisites
- Python 3.6 or higher
- No external dependencies

### Installation & Usage
```bash
# Navigate to todo_list directory
cd todo_list

# Run the application
python todo.py
