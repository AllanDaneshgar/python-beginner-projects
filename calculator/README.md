# 🧮 Python Calculator - Scientific Calculator CLI

![Python Version](https://img.shields.io/badge/python-3.6%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-stable-brightgreen)

A feature-rich command-line calculator built with Python that supports both basic and scientific operations with full calculation history tracking.

## ✨ Features

### 🔢 **Basic Operations**
- ✅ Addition (`+`)
- ✅ Subtraction (`-`)
- ✅ Multiplication (`×`)
- ✅ Division (`÷`)
- ✅ Power (`x^y`)
- ✅ Square Root (`√x`)

### 📊 **Advanced Features**
- 🕐 **Timestamped History**: Every calculation is recorded with date and time
- 💾 **Persistent Storage**: History saved in JSON format across sessions
- 🔄 **Error Handling**: Robust input validation and error messages
- 🎨 **Clean Interface**: User-friendly menu system with emoji support

### 🛡️ **Technical Features**
- Object-Oriented Design with `Calc` class
- JSON-based data persistence
- Float number support with precise formatting
- Modular code structure for easy maintenance
